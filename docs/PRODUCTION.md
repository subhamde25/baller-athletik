```sh
# looking (writes review/)

python -I tools/pick.py review/pick.jpg Product_Shots:154,165     # larger sheet of chosen stills

python -I tools/psd_peek.py "raw/Additional Assets/Task 18.psd" review/psd

# build
python -I tools/extract_brand.py
sh tools/cut_clips.sh
python -I tools/prep_stills.py
python -I tools/key_clouds.py && python -I tools/make_band.py
sh tools/build_audio.sh
python -I tools/transcribe.py film/assets/audio/vo.wav film/assets/transcript-words.json
python -I tools/make_captions.py
python -I tools/mix_preview.py                                    # loudness + the hottest 0.1 s windows

cd film
npx hyperframes check --json
npx hyperframes snapshot --at 3.3,5.95,12.6,15.8,18.45,22.83,26.6,28.08 --json
HF_SEGMENTED_CAPTURE=true npx hyperframes render --fps 30 --quality delivery --workers 2 \
  --no-low-memory-mode --protocol-timeout 900000 --resume --keep-segments -o ../renders/out.mp4
```

A render takes 8–11 minutes on this machine (7.5 GB RAM). Close heavy browsers first.

## Composition

- **Root** (`index.html`): six scene hosts on track 1, `fx` (z 3) for transitions that cross scene
  boundaries, `captions` (z 5) and `watermark` (z 6) above, then the VO, music and 26 SFX `<audio>`.
- **Scenes:** each shot is an untimed `.cam` wrapper (camera moves) holding a timed `<img>`/`<video>`
  with a `data-color-grading` payload (adjust, wheels, vignette, grain). Stills whose subject sits high
  (`clouds_man`, `deep_night`, `stretch_mint`, `muscle_sleep`) use a natural-aspect box inside an
  untimed `.lw` wrapper zoomed out from the bottom edge, a feathered top and a colour fill, so the
  captions sit above the faces.
- **Captions:** 15 groups generated by `tools/make_captions.py` from the word timings: small words
  blur in on their word, the hero word lands with scale 1.18 → 1 and blur 14 → 0, `instant` keeps
  the hook line on screen from frame 0, `scrim` adds a soft light ellipse, and the `r` line type
  rolls one hero word into the next (sleepwear. → recovery.). Edit `GROUPS`, not the HTML.
- **fx:** the cloud band (1080×3400, opaque core y 1140–2260) is timed so the core covers the frame
  exactly on the cut; the sideways drift is the same band rotated −90° and scaled 1.8.
- **Dream cloud:** `#pb-cam3` is masked by `bubble_mask.png`; GSAP tweens the CSS variable `--bub`
  (`mask-size`) 0 → 520 → 6800 px while a white puff behind it grows as the fluffy rim.
- **Vertical whip:** an SVG `feGaussianBlur` with `stdDeviation="0 N"` (y only), tweened by attribute.

## Gotchas

- **The Drive connector can't list folders shared only by link.** Drive's public `embeddedfolderview` page can (`tools/drive_tree.py`), and `drive.usercontent.google.com/download?…&confirm=t` downloads without a quota error.
- **Windows paths:** a folder named `Nikhil ` (trailing space) and 200+ character AI-prompt filenames break `os.makedirs`; `fetch_drive.py` trims folder names and shortens long file stems.
- **faster-whisper with this PyAV** fails on file input (`metadata_errors`): decode with ffmpeg and pass the array.
- **Scaling an `object-fit: cover` element shrinks its box**, so a zoom-out opened side gaps. Give the image its natural aspect at full height and scale a wrapper.
- **Never scale the timed media element itself**; tween an untimed wrapper inside the camera.
- **A full-frame overlay must start at `opacity: 0`** in CSS, or `check` fails `gsap_fullscreen_overlay_starts_visible` (the flash covered everything before 23.78 s).
- **Small layers spinning with a full-frame shot** need their transform origin set to the frame centre in their own coordinates (`-296px 260px` for the battery).
- **The renderer refuses true peaks above −1 dBFS.** `light-shimmer.mp3` peaks at −2.5 dB (an 8 kHz mean-envelope read said −32), so ×2.5 clipped the first render at +2.5 dBFS. `tools/mix_preview.py` simulates the mix from `index.html` first.
- **Low memory:** low-memory mode captures one segment and stalled at frame 608/960; 2 workers with `--resume` finish in one go. With a 5 GB browser open even small numpy jobs failed: close it.
